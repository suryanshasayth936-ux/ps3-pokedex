# ps3-pokedex

## PS Number & Project Name
- PS3: Pokedex

## API Used
- PokeAPI (`https://pokeapi.co/api/v2/pokemon?limit=50`)

## Routes
- `/` - Home page with Open Pokedex button
- `/pokemon` - Grid of 50 Pokemon cards with search filter
- `/pokemon/:name` - Detailed stats page for individual Pokemon
- `*` - 404 Not Found page
